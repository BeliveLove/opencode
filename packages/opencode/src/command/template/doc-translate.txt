先调用 `skill` 工具加载 `doc-translate`，并严格按技能契约输出。

用户参数：
$ARGUMENTS

规则：
- 如果参数里包含/看起来像文件路径（.md/.txt/.docx/.pptx/.xlsx/.pdf），先用 `doc.import` 导入再翻译。
- 不要翻译代码标识符/路径/命令；保留原样。

然后（必须）：
1) 在你生成完结构化 YAML 后，调用 `task` 工具使用 `docs` agent，把 `translated_text` 整理成最终可交付文本（可附术语表，但不要改变含义）。
2) 最终回复里同时包含两部分：
   - Part A：结构化 YAML（完整保留）
   - Part B：`docs` agent 生成的最终译文（Markdown 或纯文本，按用户需求）
