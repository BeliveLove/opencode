先调用 `skill` 工具加载 `doc-outline`，并严格按技能契约输出。

用户参数：
$ARGUMENTS

规则：
- 如果用户参数里包含/看起来像一个文件路径（.md/.txt/.docx/.pptx/.xlsx/.pdf），先调用 `doc.import`，再基于导入结果做 outline。
- 如果缺少关键信息，不要编造；在 `open_questions` 里列出来，并给出最小澄清问题（<= 8 条）。
- 输出必须包含结构化 YAML（`schema: doc.outline.v1`）。

然后（必须）：
1) 在你生成完结构化 YAML 后，调用 `task` 工具使用 `docs` agent，把该 YAML 转换成一份“可交付的 Markdown 大纲”。
2) 最终回复里同时包含两部分：
   - Part A：原始结构化 YAML（完整保留）
   - Part B：`docs` agent 生成的 Markdown 大纲（用于直接交付/粘贴到文档）
