Import a document file and extract readable text/markdown (or attach PDF).

Supported inputs:
- .md, .txt: read as text
- .docx: extract text or markdown (optional comments + track changes)
- .pptx: extract slide text with optional bullet structure + speaker notes
- .xlsx: extract sheet data (optional formula literals)
- .pdf: returned as an attachment by default; set pdfExtract to attempt text extraction (best-effort)

Not supported:
- legacy binary formats (.doc, .xls, .ppt)
